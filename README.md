A personal workspace for understanding LLM.

## Study notes

- [Interview question bank](docs/interview-question-bank.md): reported scenarios organized into Coding, Debugging, System Design, AI Project, and Uncategorized Questions. Added practice guidance is labeled separately.

## Setup

Install Python 3.14 and uv, then run:

```sh
cd src
uv sync --locked
cp .env.example .env
```

Fill in `.env` with your settings as needed.
